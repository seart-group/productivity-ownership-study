This folder contains everything needed to set up the server and replicate experiments. 

Specifically:
- the [`generate_questions`](generate_questions) and [`proxy_server`](proxy_server) folders contain the files and scripts to automatically generate questions based on user-written code;
- the [`main-environment`](main-environment) folder contains the entire server setup.
  
Please, refer to the dedicated README files ([`main-environment/README.md`](main-environment/README.md), [`generate_questions/README.md`](generate_questions/README.md), [`proxy_server/README.md`](proxy_server/README.md)) for further instructions.
