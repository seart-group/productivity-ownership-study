This folder contains everything needed to set up the server and replicate experiments. 

Specifically:
- the [`generate_questions`](server_setup/generate_questions) and [`proxy_server`](server_setup/proxy_server) folders contain the files and scripts to automatically generate questions based on user-written code;
- the [`main-environment`](server_setup/main-environment) folder contains the entire server setup.
  
Please, refer to the dedicated [`README.md`](server_setup/main-environment/README.md) file for further instructions.
